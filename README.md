# 绘宝的记忆

真正会积累的长期记忆插件。它只记一件事：**关于绘梨衣的长期信息**。

跟普通聊天记录、上下文窗口不一样——那些聊完就散了。这里的记忆是写进磁盘的，
下次开新会话还在，而且会按当前话题自动挑几条相关的带进上下文。

## 它怎么工作

1. **自动抽取**：每轮对话结束后，拿「用户说的话 + 绘宝的回复」丢给模型，
   让它整理出值得长期记住的条目，只收这几类：
   - `偏好` 明确说的喜欢/讨厌/习惯
   - `事实` 关于本人的稳定信息（身份、称呼、作息、设备、常做的事）
   - `计划` 说了要做的、约好的事
   - `事件` 发生了的、以后可能要提起的事
   - `关系` 对绘宝的要求或相处方式

   客套寒暄、临时情绪、问句、一次性查询、推测，一律不抽。

2. **按话题召回**：每次请求模型前，用本轮消息去记忆本里做字符二元组检索
   （Jaccard 相似度，不依赖向量库也不需要联网），命中且分数过线的条目会拼进
   system prompt，并额外附带几条最近更新的。

3. **主动使用**：绘宝自己也有 `memory_remember` / `memory_search` / `memory_forget`
   三个工具，可以随时记一条、翻一下以前的事、或删掉过时的记录。

## 安装

把整个目录丢进 `data/plugins/` 下，重载插件即可。无第三方依赖。

## 配置项

| 键 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enabled` | bool | `true` | 总开关 |
| `inject_enabled` | bool | `true` | 每轮把相关记忆注入系统提示词 |
| `inject_limit` | int | `6` | 按话题召回的条数（上限 12） |
| `min_score` | float | `0.3` | 召回最低相关度，越高越严格 |
| `recent_inject` | int | `4` | 额外附带最近更新的几条（上限 10） |
| `auto_extract` | bool | `true` | 每轮自动抽取长期记忆 |
| `extract_provider` | string | 空 | 抽取用哪个模型，留空=当前会话模型，建议填便宜的小模型 |
| `extract_gap` | int | `20` | 同一会话两次抽取的最小间隔（秒），防止刷屏式调用 |

## 人用命令

```
记忆                 查看条数统计和最近更新的 15 条
记忆 搜 关键词        按关键词检索
记忆 存 内容          手动存一条（来源标记为 manual，权重更高）
记忆 删 id或关键词     删掉匹配的条目
```

## 数据

记忆存在 `data/plugin_data/astrbot_plugin_memorize/memory.jsonl`，
一行一条 JSON，纯文本可以直接看、直接备份、直接手改。删掉文件等于清空记忆本。

## 注意

- 抽取是异步跑的，不会拖慢回复；但 `extract_gap` 设太小会很费 token。
- 检索是字面二元组匹配，同义词不通。想提高命中率就在条目里保留关键词原话。
- 和当前对话冲突时以当前对话为准，记得让绘宝顺手把旧的删掉。
